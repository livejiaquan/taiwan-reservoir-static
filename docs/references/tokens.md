## 字體

| 角色 | 參考頁實測 | 本站 | 差異原因 |
|------|-----------|------|---------|
| 頁面標題 h1 | Source Serif 4 34px／700，行高 1.15 | 系統襯線字（宋體）34px／700，行高 1.15；手機同 | 中文沒有 Source Serif，用系統宋體保留「襯線標題＋無襯線內文」的對比 |
| 卡片標題 h2 | 系統無襯線 15px／500，行高 1.15 | 16px／600 | 第三輪門檻：內文 ≥ 16px |
| 卡片副標 h3 | 14px／400，muted 色（墨色 60%） | 14px／400，muted 色 | 同 |
| 卡片內大字 | 28px／700，置中（「6 AM」） | **96px／600**（手機 72px），置中 | 總蓄水率是本站唯一主焦點，須 ≥ 56px 且 ≥ 第二大文字 2 倍；位置照抄（卡片內置中） |
| 卡片內文 | 14px | 16px | 第三輪門檻 |
| 表格 | 13px，th 700、td 列高約 23px，列間 1px 細線 | 16px；列間 1px 細線；每列至少 44px（觸控） | 門檻與觸控目標 |
| 圖表標註 | 10px | 12px | 第三輪門檻禁止 < 12px |
| 頁尾 | 12px | 14px | 頁尾也有連結，14px 比較好讀 |

參考頁自己的 audit 結果：`lt14 81%、lt12 12%`，最大字 34 對 28。也就是說，參考頁的字級本身不符合第三輪標準；本站照抄比例與層級（標題 → 卡片標題 → 副標 → 內文 → 標註），每一階往上調到門檻以上。

本站字級階梯：**12／14／16／28／34／72／96**。
