# 設計筆記

## 水尺牆

主視覺是「水尺牆」：20 座水庫由北到南排成 20 根直立水柱，水位高度就是蓄水率，名稱直書在下方。直書的中文在窄螢幕可以只佔 12–14px 寬，所以 390px 的手機也能把 20 根水柱並排，不必橫向捲動。

我沒有用常見的圓形液態量表：圓形容器裡水面高度與水的面積不成正比（水位 25% 時水只佔圓面積約 20%），越靠近底部與頂部越失真，持續的波浪動畫也會干擾閱讀。長方形水柱的高度與面積成正比。

水柱上畫 30%、50%、80% 三條參考線；只有低於 50% 的水庫會換成琥珀或紅色，其餘都是水藍色。

## 版面

版面參考 Observable Framework 的 dashboard 範例（<https://observablehq.com/framework/>）的比例與留白，只借結構，沒有使用它的程式碼、圖片或文案：

- 頁面左右 32px、不設最大寬度；桌面 4 欄格線、間距 16px。
- 左側大卡（總蓄水率與水尺牆）跨 2 欄 × 3 列，右側 3 張卡各跨 2 欄：狀態分布、蓄水率最低的 5 座、蓄水量與資料時間。
- 下方是整寬的各水庫清單，最後是左側有細框的說明區塊與頁尾。720–1079px 兩欄，手機單欄。
- 卡片是白底、1px 細框、圓角 12px、內距 16px、無陰影；頁面底色是墨色 4% 混白。
- 預設淺色，深色由右上角按鈕切換。

## 字體與字級

- 頁面標題用系統襯線字（宋體）34px／700；其餘中文用系統無襯線字（蘋方、Noto Sans TC、微軟正黑體），不下載中文網頁字型。
- 數字用 Barlow Semi Condensed（SIL OFL，`assets/fonts/OFL.txt`）。半窄體的數字讓水柱上的百分比放得下。只保留數字與 %、+、−、:、/，500 與 600 兩個字重各約 4KB，自行託管並 preload；使用 tabular figures，更新時不會跳動。
- 字級階梯：12／14／16／28／34／72／96px。
  - 全台總蓄水率是唯一主焦點，桌面 96px、手機 72px。
  - 內文與所有可點的控制項 16px；卡片副標與次要說明 14px。
  - 12px 只用在水尺牆的參考線刻度與手機上的直書水庫名。

## 色彩

| Token | 淺色 | 深色 | 用途 |
|-------|-----|-----|------|
| `--ink` | `#0F2333` | `#E4ECF2` | 主要文字 |
| `--water` | `#2B79B0` | `#4FA3DC` | 水位（充足、正常） |
| `--low` | `#B26B00`（文字 `#8A4F00`） | `#F2A33A` | 偏低 30–50% |
| `--critical` | `#D03B3B`（文字 `#A82424`） | `#FF7070` | 嚴重 <30% |

文字對比至少 4.5:1，圖形至少 3:1，已用 WCAG 公式逐一計算。

## 動效

- 首次載入不跑進場動畫，資料一到就直接顯示最終水位；等待 API 時水尺牆中央會寫出「正在讀取水利署資料」。
- 之後每次資料更新，水位用 300ms ease-out 過渡到新高度。
- `prefers-reduced-motion: reduce` 時全部停用。

## 圖示與品牌標記

UI 圖示只用 [Lucide](https://lucide.dev/)（ISC 授權），原始檔來自 `lucide-static` 1.61.0，放在 `assets/icons/` 並內嵌成 `index.html` 開頭的 sprite，執行時不載入外部 CDN。繪製參數統一為 24px 格、筆畫 1.75、圓頭圓角、`currentColor`；尺寸只有 16／20／24。

| 用途 | Lucide |
|------|--------|
| 重新整理 | `refresh-cw` |
| 切換深色／淺色 | `moon`／`sun` |
| 展開清單列 | `chevron-down` |
| 資料無法驗證 | `triangle-alert` |
| 開新視窗 | `external-link` |

品牌標記是藍色（`#2B79B0`）圓角方形（圓角為邊長的 22%）裡的白色 Lucide `waves`（佔邊長 58%、筆畫 2）。`assets/brand/mark.svg` 是唯一來源，`favicon.svg`、`apple-touch-icon.png`（180px）與 `og-image.png` 都從它輸出。

## 其他同類產品

設計前我看過這些水情與水庫產品，各自拿來參考不同的地方：

- 水利署防災資訊網「水庫水情」：官方資料最完整，但是純表格；每列都有自己的觀測時間，並註明各水庫更新不同步。
- 用數據看台灣「台灣水庫即時水情」：北、中、南分區與容量比較圖；同樣標示各水庫更新時間。
- 美國墾務局的西部水資料儀表板與加州 CDEC：以「茶杯」圖比較目前蓄水與歷史平均。水利署的 API 沒有歷史平均，所以這個頁面改用過去 24 小時的逐時資料顯示變化。
- 澳洲氣象局 Water Storage：以「% full」呈現，並與去年同期比較。

本專案只借概念，沒有複製任何程式碼。
