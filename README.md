# 台灣水庫即時監控系統 - 靜態網頁版

這是一個純前端的台灣水庫即時監控系統，使用現代化的 HTML、CSS、JavaScript 技術開發。

## 專案特色

- 🌊 **官方水庫資料監控** - 直接調用水利署 API；無法驗證官方資料時不顯示推測值
- 📱 **響應式設計** - 完美適配桌面、平板、手機各種設備
- 🎨 **美觀現代化界面** - 採用現代化設計語言，視覺效果優雅
- ⚡ **純前端實現** - 無需後端服務器，可直接部署到靜態託管服務
- 🔄 **自動定時更新** - 每5分鐘自動刷新資料
- 📊 **互動式圖表** - 使用 Chart.js 提供豐富的視覺化效果
- 🎯 **直觀資訊展示** - 大字體、清晰圖示、漸層進度條
- 🏗️ **模組化架構** - 代碼結構清晰，易於維護擴展

## 設計特點

### 🎨 視覺設計
- **現代化卡片設計**：圓角邊框、柔和陰影、漸層背景
- **直觀進度顯示**：水平進度條 + 水滴指示器取代傳統圓形進度條
- **大字體顯示**：重要數據使用大字體，提高可讀性
- **色彩語意化**：不同蓄水率使用不同顏色（綠/藍/橙/紅）
- **動畫效果**：流暢的載入動畫、懸停效果、轉場動畫

### 📐 響應式布局
- **桌面端**：最多4欄顯示（1400px+）
- **筆記型電腦**：3欄顯示（992px-1399px）
- **平板**：2欄顯示（768px-991px）
- **手機**：單欄顯示（<768px）

## 快速開始

### 本地開發
```bash
# 下載專案
git clone [repository-url]
cd taiwan-reservoir-static

# 啟動本地服務器（任選一種方式）
# Python 3
python3 -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080

# Node.js (需先安裝 http-server)
npx http-server -p 8080

# PHP
php -S localhost:8080
```

然後在瀏覽器開啟 http://localhost:8080

## 功能特色

### 1. 🏠 首頁總覽
- **統計卡片**：顯示本次可用水庫數、容量加權合計蓄水率與各蓄水率區間數量
- **總覽圖表**：橫條圖顯示所有水庫蓄水率排序
- **即時更新**：分開顯示水量觀測、容量資料及成功擷取時間，統一使用台北時區；支援手動重新擷取

### 2. 🗺️ 地區分類
- **地區篩選**：北部、中部、南部水庫清單；東部按鈕明確說明尚未納入
- **動態切換**：點擊地區按鈕即時篩選顯示
- **響應式網格**：根據螢幕大小自動調整顯示欄數

### 3. 💧 水庫詳情卡片
- **現代化設計**：卡片式布局，懸停動畫效果
- **進度條顯示**：水平進度條 + 漸層色彩
- **水位指示器**：5個水滴圖案顯示水位狀態
- **詳細資訊**：有效容量、目前水量、蓄水率、水位狀態
- **視覺化圖標**：每項資訊配有對應圖標

### 4. ⚠️ 低蓄水率提醒
- **智能篩選**：自動顯示蓄水率低於50%的水庫
- **區間分類**：低於30%、30%至未滿50%；不代表官方限水或停水警報
- **快速定位**：點擊預警卡片可快速跳轉到對應水庫

### 5. 📊 圖表分析
- **總覽圖表**：所有水庫蓄水率橫條圖
- **互動功能**：點擊圖表可跳轉到對應水庫卡片
- **工具提示**：懸停顯示詳細資訊

## API 資料來源

- **主要來源**: 水利署水利資料開放平台的「水庫水情資料」與「水庫每日營運狀況」API
- **資料處理**: 以水庫代碼合併最新有效蓄水量與有效容量，再計算蓄水率
- **失敗策略**: API 無法使用或回傳格式異常時，醒目標示無法確認官方資料，不顯示模擬水情
- **擷取頻率**: 本站每5分鐘嘗試擷取，不等於官方每5分鐘更新
- **快取機制**: 本地儲存5分鐘快取，減少API請求

## 資料判讀與開發檢查

- 本站對照 20 座水庫（北 5、中 7、南 8）；東部與離島尚未納入。缺資料不代表零蓄水。
- 觀測時間與容量來源的統計時間可能不同；來源未附時區時按台北 UTC+8 解讀。讀取 5 分鐘快取不會改寫成功擷取時間。
- 合計蓄水率以「蓄水量總和 ÷ 有效容量總和」計算，只適用本次顯示水庫；不是全台總量，也不是同時刻觀測。
- 觀測超過 6 小時加註提醒。可用水庫少於 10 座、觀測超過 48 小時或超前 1 小時時，整份快照不顯示；這些是本站檢查門檻。
- 百分比區間不是官方水情燈號。沒有歷年同期資料，不能只靠百分比判斷季節異常、乾旱或自來水供應。
- 詳見 [資料來源與驗證紀錄](docs/DATA_CONTEXT.md)。

本專案不需要打包或額外依賴。使用 Node.js 18+ 執行離線回歸與靜態檢查：

```bash
node --test tests/*.test.js
TZ=America/Los_Angeles node --test tests/*.test.js
TZ=Asia/Taipei node --test tests/*.test.js
git diff --check
```

測試涵蓋 API 失敗、部分覆蓋、過期與未來觀測、日期格式與時區、來源排序、數值缺值、快取擷取時間、容量加權、東部空狀態、重複刷新及歷史圖不造數據。測試 fixture 是明確標示的合成資料，不代表當前水情。瀏覽器/CORS 和手機排版仍須另行驗證，Node 測試不能代替視覺檢查。
