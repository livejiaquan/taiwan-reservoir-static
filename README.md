# 台灣水庫即時監控系統 - 靜態網頁版

這是一個純前端的台灣水庫即時監控系統，使用現代化的 HTML、CSS、JavaScript 技術開發。

## 專案特色

- 🌊 **即時水庫資料監控** - 直接調用水利署API獲取最新水庫蓄水資料
- 📱 **響應式設計** - 完美適配桌面、平板、手機各種設備
- 🎨 **美觀現代化界面** - 採用現代化設計語言，視覺效果優雅
- ⚡ **純前端實現** - 無需後端服務器，可直接部署到靜態託管服務
- 🔄 **自動定時更新** - 每5分鐘自動刷新資料
- 📊 **互動式圖表** - 使用 Chart.js 提供豐富的視覺化效果
- 🎯 **直觀資訊展示** - 大字體、清晰圖示、漸層進度條
- 🏗️ **模組化架構** - 代碼結構清晰，易於維護擴展

## 設計特點

### 🎨 視覺設計
- **現代化卡片設計**：圓角邊框、柔和陰影、漸層背景
- **直觀進度顯示**：水平進度條 + 水滴指示器取代傳統圓形進度條
- **大字體顯示**：重要數據使用大字體，提高可讀性
- **色彩語意化**：不同蓄水率使用不同顏色（綠/藍/橙/紅）
- **動畫效果**：流暢的載入動畫、懸停效果、轉場動畫

### 📐 響應式布局
- **桌面端**：最多4欄顯示（1400px+）
- **筆記型電腦**：3欄顯示（992px-1399px）
- **平板**：2欄顯示（768px-991px）
- **手機**：單欄顯示（<768px）

## 技術棧

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **圖表庫**: Chart.js (CDN)
- **圖標庫**: Bootstrap Icons (CDN)
- **字體**: Google Fonts - Noto Sans TC (CDN)
- **部署**: 可部署到任何靜態網站託管服務

## 快速開始

### 本地開發
```bash
# 下載專案
git clone [repository-url]
cd taiwan-reservoir-static

# 啟動本地服務器（任選一種方式）
# Python 3
python3 -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080

# Node.js (需先安裝 http-server)
npx http-server -p 8080

# PHP
php -S localhost:8080
```

然後在瀏覽器開啟 http://localhost:8080

### 直接部署
可直接將整個專案資料夾部署到以下平台：
- **GitHub Pages** - 免費靜態網站託管
- **Netlify** - 拖拽部署，自動CI/CD
- **Vercel** - 快速部署，全球CDN
- **Firebase Hosting** - Google的靜態託管服務
- **Surge.sh** - 簡單的靜態網站部署

## 功能特色

### 1. 🏠 首頁總覽
- **統計卡片**：顯示水庫總數、平均蓄水率、各狀態水庫數量
- **總覽圖表**：橫條圖顯示所有水庫蓄水率排序
- **即時更新**：顯示最後更新時間，支援手動刷新

### 2. 🗺️ 地區分類
- **地區篩選**：北部、中部、南部、東部地區分類
- **動態切換**：點擊地區按鈕即時篩選顯示
- **響應式網格**：根據螢幕大小自動調整顯示欄數

### 3. 💧 水庫詳情卡片
- **現代化設計**：卡片式布局，懸停動畫效果
- **進度條顯示**：水平進度條 + 漸層色彩
- **水位指示器**：5個水滴圖案顯示水位狀態
- **詳細資訊**：有效容量、目前水量、蓄水率、水位狀態
- **視覺化圖標**：每項資訊配有對應圖標

### 4. ⚠️ 預警系統
- **智能篩選**：自動顯示蓄水率低於50%的水庫
- **分級預警**：嚴重缺水(<30%)、水位偏低(30-50%)
- **快速定位**：點擊預警卡片可快速跳轉到對應水庫

### 5. 📊 圖表分析
- **總覽圖表**：所有水庫蓄水率橫條圖
- **互動功能**：點擊圖表可跳轉到對應水庫卡片
- **工具提示**：懸停顯示詳細資訊

## API 資料來源

- **主要來源**: 水利署水利資料開放平台的「水庫水情資料」與「水庫每日營運狀況」API
- **資料處理**: 以水庫代碼合併最新有效蓄水量與有效容量，再計算蓄水率
- **備用方案**: 內建模擬資料（確保在 API 無法使用時仍可正常顯示）
- **更新頻率**: 每5分鐘自動更新
- **快取機制**: 本地儲存5分鐘快取，減少API請求
